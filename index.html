I build software for work I have done myself.

Seven years as a marine engineer officer, then quality control on wind turbine blades, and now maintenance on an aviation fuel facility in Charlotte. For about a year I have been teaching myself mobile development alongside the day job.

Every application here started the same way: I watched someone solve a problem with a plastic wheel chart, a clipboard, or a bound paper logbook, and I already knew the procedure well enough to build the digital version correctly. The domain knowledge came first. The code came second.

I am relocating to Nova Scotia in November 2026 and hold a Canadian open work permit valid through 2029.

Projects

  • FuelOps

    Platform
    React Native / Expo
    Replaces
    Gammon GTP-3012-1A API gravity wheel
    Status
    Field-validated, preparing Play Store release

    Fuel density and API gravity calculation for aviation, marine, and tank farm operators. Implements ASTM D1250 Tables 54B and 6B iteratively, plus API MPMS 11.2.1 compressibility. Checked against six real measurements at an airport fuel facility, which is how two corrections were found that the textbook formulas do not mention.

  • RampDispatch

    Platform
    Kotlin / Jetpack Compose
    Replaces
    Whiteboard and radio fuel dispatch
    Status
    Portfolio project, mock data only

    Offline-first aircraft fuel dispatch board with role-based access, an eight-step fuelling wizard, and per-aircraft tank layouts. Room is the single source of truth, so the board stays usable when the ramp loses signal. Built from my own years working the ramp as a fueller and team leader.

    How RampDispatch works

  • EngineRoomLog

    Platform
    Kotlin / Compose / Room / Firebase
    Replaces
    The paper engine room logbook
    Status
    Portfolio project

    Watch entries, two-stage sign-off, and write-once PDF exports verified with SHA-256, synced across a fleet when a connection is available. The permission model and the sign-off rules come from seven years of keeping these logs by hand at sea, including the awkward cases such as a watch with only one engineer on it.

    How EngineRoomLog works

  • RoadTripPlanner

    Platform
    React Native
    Subject
    National parks, trails, and city parks
    Status
    Portfolio project

    A discovery app that orchestrates six APIs — NPS, OSM Overpass, YouTube, Google Places, OpenWeather, and Recreation.gov — behind lazy enrichment, tiered caching, and multi-endpoint retry. The interesting problem here was not the interface but keeping request cost and failure rate down when half the sources are public infrastructure that can be slow or briefly unavailable.
